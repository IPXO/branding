## Download

- Latest brand pack: https://www.ipxo.com/press-releases/
- Direct asset paths (stable): `Logo/` and `Symbol/`

## Quick Usage Rules

- Use only official assets from this repository or published releases.
- Keep proportions, spacing, and colors unchanged.
- Do not stretch, recolor, rotate, or redraw the logo/symbol.
- Do not use IPXO marks in ways that imply endorsement or partnership.
- See `TRADEMARK.md` and `BRAND_GUIDELINES.md` for full policy.

## Repository Contents

- `Logo/` wordmarks and lockups in `SVG`, `PNG`, and `Print` formats
- `Symbol/` icon-only marks in `SVG`, `PNG`, and `Print` formats
- `BRAND_GUIDELINES.md` export and technical standards
- `TRADEMARK.md` allowed and prohibited usage
- `LICENSE` legal terms for this repository

## Compatibility Notice

Existing asset folder names and paths are intentionally preserved to avoid
breaking downstream consumers that may rely on frozen URLs or file references.
