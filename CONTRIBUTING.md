# Contributing

## Scope

This repository distributes official IPXO branding assets. Contributions should
focus on asset quality, packaging, and policy clarity.

## Before Opening a PR

- Keep existing `Logo/` and `Symbol/` paths stable.
- Follow `BRAND_GUIDELINES.md`.
- Run local checks:

```bash
./scripts/brand_check.sh
```

## Typical Contribution Types

- Add missing format/size variants while preserving compatibility.
- Improve brand documentation and usage guidance.
- Improve automation for validation and release packaging.

## Not Accepted Without Prior Approval

- Renaming/moving canonical asset files or directories.
- Replacing official marks with redesigned marks.
- Policy or legal changes that conflict with `TRADEMARK.md`.

## Issue-First Changes

Open an issue first for major changes to structure, legal text, or release model.
